# SQL Sales Analysis Project

## Project Overview
This project analyzes a mini sales dataset using PostgreSQL and SQL. The goal is to understand sales performance, product performance, regional sales, and payment methods.

## Tools Used
- PostgreSQL
- pgAdmin 4
- SQL

## Dataset
The dataset contains sales records with fields such as:
- Order ID
- Order Date
- Product
- Category
- Quantity
- Unit Price (BDT)
- Sales (BDT)
- Payment Method
- Region

## Analysis Performed
1. Total sales, total quantity, and order count
2. Product-wise sales analysis
3. Category-wise sales analysis
4. Region-wise sales analysis
5. Payment method analysis
6. Highest-sales order
7. Daily sales analysis
8. Average order value
9. Data quality checks
10. Sales classification using CASE WHEN
11. Group filtering using HAVING
12. Regional sales contribution using CTEs
13. Product ranking using window functions
14. Product and region comparison
15. Daily sales changes using LAG()

## Project Files
- sales_analysis.sql — SQL queries used in the analysis
- mini_sales_dataset.csv — Dataset used for the project

## Key Objectives
- Practice SQL querying and aggregation
- Identify product and regional sales patterns
- Validate data quality
- Generate insights to support business decisions
